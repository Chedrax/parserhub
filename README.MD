# ParserHub

Platform for managing and running web parsers.

## Overview

ParserHub is a scalable parsing platform that allows users to create, manage and execute parsers through a unified interface.

The project focuses on:
- scalable backend architecture;
- asynchronous task execution;
- parser management;
- data processing pipeline.

## Features

Current:

- User authentication
- Parser management
- Task execution
- Result storage

Planned:

- Async workers
- Scheduler
- Real-time monitoring
- Plugin system


## Architecture

Frontend:
Next.js + TypeScript

Backend:
FastAPI + Python

Database:
PostgreSQL


## Development

Requirements:

- Docker
- Python
- Node.js
