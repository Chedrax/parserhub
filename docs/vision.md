# ParserHub Vision


## Problem

Many websites contain valuable data, but collecting and maintaining this data requires custom scripts that are difficult to manage and scale.


## Solution

ParserHub is a unified platform for developing, running and monitoring web parsers.

The system provides:

- common parser interface;
- task management;
- execution monitoring;
- data storage;
- analytics.


## Goals

The main goals:

- create scalable parsing architecture;
- support multiple parser implementations;
- separate parser logic from platform logic;
- provide reliable task execution.


## Non-goals

ParserHub is not:

- a universal scraping bypass tool;
- a system for uncontrolled plugin execution;
- a replacement for existing databases.


## Target users

- developers;
- companies collecting public data;
- analysts.
